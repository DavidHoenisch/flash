# Message fixtures

`declaration-opening.txt` is the first body paragraph of the U.S. Declaration of
Independence, starting “When in the Course of human events”. Source:
[National Archives transcription](https://www.archives.gov/founding-docs/declaration-transcript).
The original text is public domain. Its trailing file newline is omitted from the
406-byte ASCII payload used for the first modem sound test.

This is openly readable test content. No compression, encryption, or scrambling is
applied in the experiment 0001/0002 framing used for this transmission.
